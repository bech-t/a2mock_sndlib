# Politique de sécurité

## Signaler une vulnérabilité

Merci de **ne pas** ouvrir d'issue publique pour un problème de sécurité.

Utilisez plutôt le signalement privé de vulnérabilités de GitHub :
[Security Advisories](https://github.com/bech-t/a2mock_sndlib/security/advisories/new)
(onglet *Security* du dépôt → *Report a vulnerability*).

Vous pouvez attendre une réponse sous quelques jours. Ce projet est
maintenu bénévolement sur mon temps libre, merci de votre patience.
